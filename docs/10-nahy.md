# کجا نباید وقف کرد — تحلیل کلمه‌به‌کلمهٔ آیه

موتور برای هر آیه، کلمه‌به‌کلمه بررسی می‌کند که وقف روی کدام کلمه
**غلط یا خطرناک** است و چرا. این تحلیل بر پایهٔ روابط لفظی (اعرابی)
آشکارِ متن عثمانی است — همان چیزهایی که در `docs/01-osul.md` به‌عنوان
«رابطهٔ لفظی» آمده.

## قواعد تحلیل

| نوع | قاعده | مثال |
| --- | --- | --- |
| حرف جر | وقف روی حرف جر بدون مجرور | «فِی»، «مِن»، «إِلَى»، «عَنْ» |
| مضاف و مضاف‌الیه | وقف روی مضافِ بی‌تنوین که اسم معرفهٔ بعدش مال اوست | «بِسْمِ» بدون «الله» (فاتحه) |
| موصول و صله | وقف روی موصول بدون صله | «ٱلَّذِی»، «ٱلَّتِی»، «ٱلَّذِینَ» |
| قول و مقول | وقف روی فعل قول بدون سخنِ پس از آن | «قَالَ»، «قُلْ»، «يَقُولُونَ» |
| ادات شرط | وقف روی ادات شرط بدون جزا | «إِن»، «لَو»، «لَوْلَا»، «إِذَا»، «كُلَّمَا» |
| ادات ناصبه/مشبهه | وقف روی «أن/إن» و خواهرانش | «أَنْ»، «فَإِنَّ»، «لَعَلَّ»، «لٰكِنَّ» |
| نفی | وقف روی ادات نفی بدون منفی | «لَا»، «مَا»، «لَمْ»، «لَنْ»، «لَيْسَ» |
| نفی جنس | وقف روی اسم «لا» پیش از رسیدن «إلا» | «لا إِلٰهَ» بدون «إِلا الله» |
| استثنا | وقف روی «إلا» یا جدا کردن مستثنی‌منه از آن | «إِلَّا» |
| عطف | وقف روی حرف عطف تنها | «ثُمَّ»، «بَلْ»، «أَوْ» |
| ظرف إذ | وقف روی «إذ» بدون جمله‌اش | «إِذْ» |

علامت‌های چاپی هم لحاظ می‌شوند:

- **ممنوع (لا / ۙ)**: صریح «نایست» — ممنوع.
- **صلی (ۖ)** و **معانقه (ۛ)**: احتیاط (وصل اولی است؛ یا فقط روی یکی از دو نقطه).
- اگر مصحف **لازم/قلی/جایز** گذاشته باشد، حکم چاپی محترم است و چیزی نمی‌گوییم.

## دو شدت

- **ممنوع**: وقف معنا را ناقص یا فاسد می‌کند.
- **احتیاط**: وقف جایز است ولی مرجوح (صلی، معانقه، مستثنی‌منه).

## استفاده

```bash
python3 -m engine nahy «بقره ۲۵۸»   # فقط تحلیل «نایست»
python3 -m engine «بقره ۲۵۸»        # پاسخ کامل؛ جدول «کجا نباید وقف کرد» +
                                     # بند «وقف غلط کلمه‌به‌کلمه» در بخش ۴
```

در وب و API (کلید `nahy`) هم همین جدول می‌آید.

## محدودهٔ صدق تحلیل

این تحلیل قواعد لفظی **آشکار و قطعی** را می‌گیرد (دقت بالا، پوشش نه کامل).
روابطی که بدون اعراب کامل قابل تشخیص نیستند (نعت و منعوت، بدل، مبتدا و خبر)
عمداً گفته نمی‌شوند تا ادعای نادرست نشود. حکم نهایی همیشه با علامت چاپی
و جدول محشی سنجیده می‌شود.
