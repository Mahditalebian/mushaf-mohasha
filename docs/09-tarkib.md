# ترکیب جدول محشی و علائم چاپی — «بهترین مواضع»

از دو منبع، یک فهرست رتبه‌بندی‌شده ساخته می‌شود تا برای هر آیه،
**بهترین جاهای وقف و ابتدا** مشخص باشد.

## دو منبع

| منبع | پوشش | نقش |
| --- | --- | --- |
| جدول وقف و ابتدا (سید علی حسینی، بر پایهٔ مصحف محشی) | بقره تا ماعون — ۸۷۴ موضع | استدلال معنایی؛ هر جا باشد اولویت دارد |
| علائم چاپی مصحف (متن عثمانی Tanzil همراه pause marks) | کل قرآن — ۶۲۳۶ آیه | حکم چاپی هر موضع |
| رأس آیه | همیشه | وقف سنت |

## امتیازدهی

| موضع | امتیاز |
| --- | --- |
| اولویت اول / مورد اول جدول محشی | ۱۰۰ / ۹۵ |
| تأیید دو منبع (محشی + علامت چاپی همرأی) | امتیاز پایه + ۲۰ |
| قلی (وقف اولی) | ۷۵ |
| مورد دوم / اولویت دوم | ۸۵ / ۸۰ |
| رأس آیه (سنت) | ۶۵ |
| معانقه / جایز / سکت | ۶۰ / ۵۵ / ۴۵ |
| اضطراری | ۳۰ |
| صلی (وصل اولی) به‌عنوان جای وقف | ۲۵ |

## حالت‌های ویژهٔ همرأیی

- **تأیید دو منبع**: جدول محشی و علامت چاپی (لازم، قلی، جایز، معانقه، سکت)
  روی یک کلمه همرأی‌اند — مطمئن‌ترین جای وقف. بالاترین امتیاز.
- **محشی: فقط اضطراری · چاپی: ممنوع**: علامت چاپی وقف برنامه‌ریزی‌شده را
  ممنوع می‌داند؛ جدول فقط برای اضطرار نفس اجازه می‌دهد. مکمل هم‌اند.
- **اختلاف دو منبع**: جدول موضع وقف گذاشته ولی علامت چاپی ممنوع است —
  امتیاز سقف ۴۰ می‌گیرد و در ترتیل جانب احتیاط.

## استفاده

```bash
python3 -m engine best «بقره ۹۱»      # فقط فهرست بهترین مواضع
python3 -m engine «بقره ۹۱»           # پاسخ کامل چهاربخشی + بخش بهترین مواضع
```

در وب (پورت ۸۷۶۵) بخش «بهترین مواضع (ترکیب محشی + علائم چاپی)» زیر
جدول وقف/ابتدا می‌آید و در API هم کلید `best` دارد.

## آمار (python3 -m engine check)

پوشش بهترین مواضع: کل ۶۲۳۶ آیه (رأس آیه همیشه هست). تعداد مواضع
«تأیید دو منبع» از تطبیق خودکار محاسبه می‌شود.

## نسبت با فایل چاپی (طبع و نشر)

این ترکیب بر پایهٔ متن عثمانی همین ریپو ساخته شده که همان نظام علائم
مصحف مرکز طبع و نشر است. اگر نسخهٔ PDF چاپی با آن فرق داشت (مثلاً علامتی
جابه‌جا شده باشد)، اختلافش را می‌توان صفحه‌به‌صفحه چک کرد:
`python3 -m engine «آیه»` کارت تطبیق صفحه را می‌دهد.
