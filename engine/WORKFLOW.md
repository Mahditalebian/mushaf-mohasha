# گردش کار بعد از کلون

1. `git clone` و `cd mushaf-mohasha`
2. `python3 -m engine check` — داده کامل است؟
3. `python3 -m engine serve` یا `./run.sh`
4. آیه را در صفحه یا با `python3 -m engine «…»` بپرس.
5. جواب چهاربخشی از روی جدول محشی + علائم + اصول می‌آید.
6. هیچ commit و هیچ فایل جدیدی برای آن سؤال ساخته نمی‌شود.
