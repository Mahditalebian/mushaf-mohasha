# موتور پرسش

بعد از کلون، از ریشهٔ ریپو کار می‌کند. سؤال را ذخیره نمی‌کند.

```
پرسش تو
    ↓
engine.parse   تشخیص آیه / موضوع / علامت
    ↓
data/quran-uthmani.txt     متن + علائم وقف
data/jadval_raw/           جدول محشی: وقف روی → ابتدا از
data/pages.tsv             صفحهٔ مصحف ۶۰۴صفحه‌ای
docs/*.md                  اصول و غلط‌های مشهور
ayat/**                    فقط اگر از قبل یادداشت باشد
    ↓
استدلال چهاربخشی + جدول
```

## اجرا

از ریشهٔ ریپو:

```bash
python3 -m engine check
python3 -m engine "بقره ۹۱"
python3 -m engine serve
```

صفحهٔ HTML: http://127.0.0.1:8765  (راهنما: [`LOCAL.md`](../LOCAL.md))

`web/index.html` را مستقیم باز نکن؛ باید `serve` روشن باشد.

## چه چیزی خوانده می‌شود

| منبع | نقش |
| --- | --- |
| `data/quran-uthmani.txt` | متن عثمانی و علائم |
| `data/jadval_raw/` | جدول حسینی بر پایهٔ مصحف محشی |
| `data/pages.tsv` | شماره صفحه و جزء |
| `docs/` | اصول معنایی، علائم، غلط‌ها |
| `ayat/` | فقط یادداشت ثابت قبلی |

## چه چیزی نوشته نمی‌شود

- سؤال‌های چت
- جواب‌های جلسه
- تاریخچه

ریپو منبع ثابت است. جلسهٔ پرسش، مصرف‌کننده است.
