# موتور پرسش

این برنامه سؤال را ذخیره نمی‌کند. فقط از دادهٔ همین ریپو می‌خواند و یک بستهٔ زمینه می‌سازد.

```
پرسش تو
    ↓
engine.parse   تشخیص آیه / موضوع / علامت
    ↓
data/quran-uthmani.txt     متن + علائم وقف
docs/*.md                  اصول و غلط‌های مشهور
ayat/**                    فقط اگر از قبل یادداشت باشد
    ↓
بستهٔ زمینه
    ↓
جواب چهاربخشی (وقف / وصل / ابتدا / اشتباه)
```

## اجرا

از ریشهٔ ریپو:

```bash
python3 -m engine "بقره ۹۱"
python3 -m engine "یونس 65"
python3 -m engine "2:26"
python3 -m engine "همه وقف لازم"
python3 -m engine "معانقه چیست"
```

یا:

```bash
python3 scripts/ask.py "آیه 91 بقره"
```

## چه چیزی خوانده می‌شود

| منبع | نقش |
| --- | --- |
| `data/quran-uthmani.txt` | متن عثمانی و علائم |
| `docs/` | اصول معنایی، علائم، غلط‌ها، کلمه‌های خاص، مواضع لازم |
| `ayat/` | فقط اگر قبلاً یادداشتی باشد؛ سؤال جدید اینجا نوشته نمی‌شود |

## چه چیزی نوشته نمی‌شود

- سؤال‌های چت
- جواب‌های جلسه
- تاریخچه

ریپو منبع ثابت است. جلسهٔ پرسش، مصرف‌کننده است.
